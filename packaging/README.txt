halobar · 使用说明
=================

这是一个免安装的绿色版本。解压到任意目录（支持中文路径），双击 halobar.exe 即可运行。

第一次运行
----------
1. 双击 halobar.exe；
2. 程序会缩到右下角托盘中，并在浏览器里打开控制台（地址只在本机有效）；
3. 桌面快捷方式：在控制台点「创建桌面快捷方式」，或右键托盘图标选择同名菜单项。

Windows 可能提示"未知发布者"，这是因为程序没有代码签名，点"更多信息 → 仍要运行"。
若杀毒软件拦截，请把 halobar.exe 加入白名单。

需要什么
--------
· 花再 Halo PixelBar 音箱，用 USB 连电脑，切到声卡输入（指示灯红色）；
· 想显示歌词：开箱即用，但播放进度靠估算；
· 想要精准进度：需要给官网版网易云安装 BetterNCM + InfLink-rs + 6K Labs，
  控制台顶部的「环境与插件」里有分步指引和下载链接。

数据与卸载
----------
配置、日志、歌词缓存保存在：
  %LOCALAPPDATA%\halobar

卸载 = 删除程序目录，再按需删除上面的数据目录。

注意
----
· 上传自定义图片会覆盖音箱里的自定义场景槽，官方原图需用 TempoHub / App 重新发送；
· 本程序与 EDIFIER / 花再没有隶属关系，使用风险自负；
· 程序不会开机自启，也不会联网上传任何数据（只访问网易云歌词接口与本地端口）。
