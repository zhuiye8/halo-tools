# 据此确定的本项目设计规范（草案）

## 1. 排版

- 基准 14px，比例 1.25（Utopia 思路）：
  - 11px 标签 · 12px 辅助 · 14px 正文 · 17px 强调 · 21px 卡片标题 · 26px 页面主标题 · 32px 歌词大字
- 标签用 11px、字距 +0.06em、颜色降一档，不使用全大写英文。
- 数字（时间、帧数、版本号）用等宽字体，避免跳动。
- 行高：正文 1.6，标题 1.25。

## 2. 间距与形状

- 4px 基准：4 / 8 / 12 / 16 / 24 / 32。
- 卡片圆角 16px，控件 10px，胶囊 999px；**不再卡片套卡片**。
- 卡片间距 16px，内边距 20px。

## 3. 配色

- 底色 `#FBFBFD`，卡片 `#FFFFFF`，描边 `#ECECF2`。
- 文字 `#1C1B22` / 次要 `#6B6779` / 弱化 `#9A96A8`。
- **单一强调色**：电光紫 `#6C4CFF`（来自 MVS 的 `#0E1ADF` 思路，柔化后更适合长时间看）。
- 语义色：成功 `#1F9D6B`、警告 `#C7761A`、错误 `#D93A4A`。
- 按 Radix 的 12 级思路使用强调色：背景用最浅两级、悬停中间、描边中段、文字最深。
- **移除**：卡片顶部彩色渐变条、面板左侧彩色竖条、米黄"AI 配色"。

## 4. 动效

- 时长 120–200ms，缓动 `cubic-bezier(.2,.8,.2,1)`（Emil Kowalski 的"克制又跟手"）。
- 只动 `transform` 与 `opacity`，绝不写 `transition: all`。
- 列表/卡片出现用 8–12px 位移 + 淡入，不缩放超过 1.02。
- 尊重 `prefers-reduced-motion: reduce`。
- 状态变化（同步中/已暂停）用一次 400ms 的呼吸，不要常驻闪烁。

## 5. 可读性与无障碍

- 正文对比度 ≥ 4.5:1，弱化文字也要 ≥ 3:1。
- 输入框字号 ≥16px（避免 iOS 聚焦自动放大）。
- 触控目标 ≥40px；键盘 Tab 有清晰焦点环。
- 所有状态不只靠颜色表达（加文案或图标）。

## 6. 明确要避免的「AI 味」清单

来自 Impeccable 与 Vercel Guidelines，对照我们当前界面：

| 我们现在的做法 | 问题 | 改法 |
| --- | --- | --- |
| 每张卡片顶部一条彩色渐变线 | 装饰性、无信息 | 去掉，用留白和字重区分层级 |
| 环境面板左侧渐变竖条 | 典型 AI 式提示条 | 改成浅底 + 图标 + 文字层级 |
| 标题旁大量 emoji（🎵🖼️📝🎀） | 廉价感 | 换成 16px 线性图标或纯文字 |
| 圆角/阴影随手定 | 缺乏系统 | 统一 16/10/999 与两级阴影 |
| 字号 13/19/22 跳变 | 无比例 | 按 1.25 阶梯 |

## 7. 落地顺序

1. 先定 design tokens（CSS 变量：颜色、字号、间距、圆角、阴影、动效曲线）；
2. 改布局：单列长页面 → Bento 网格（播放卡片占 2 列、环境为窄卡、素材编辑器跨列）；
3. 替换装饰元素（去彩条、去 emoji、去渐变竖条）；
4. 加动效：卡片入场、按钮按压、数值变化；
5. 用 Vercel Guidelines 逐条自查一遍。
